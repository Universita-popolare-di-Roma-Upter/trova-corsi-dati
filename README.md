# Upter · Trova corsi

Web app per cercare i corsi dell'Università popolare di Roma – Upter APS.

Indirizzo dell'app: https://universita-popolare-di-roma-upter.github.io/trova-corsi-dati/

- `corsi.json` si aggiorna ogni mattina (dal lunedì al sabato) con un'attività automatica a partire dai dati della Segreteria.
- Il file contiene solo dati pubblici sui corsi: titolo, docente, giorni, sede, costo, descrizione, stato dei posti (esauriti / ultimi posti) e link di iscrizione. Non contiene numeri di iscritti, incassi o nomi di soci.
- Per modifiche all'app (non ai dati) aumentare `VERSIONE` in `sw.js`.
